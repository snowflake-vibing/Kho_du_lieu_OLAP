HUONG DAN RESTORE DATABASE CHO SSAS
===================================

1. Mo SQL Server Management Studio (SSMS).
2. Ket noi vao SQL Server Instance cua ban.
3. Click phai chuot vao muc "Databases" -> chon "Restore Database...".
4. O phan Source:
   - Chon "Device" -> click nut [...]
   - Nhan "Add" -> tro toi file `DW_Football_Analytics.bak` vua giai nen.
   - Nhan OK.
5. Kiem tra ten Database o muc "Destination": `DW_Football_Analytics`.
6. Nhan OK de tien hanh Restore.

Kiem tra sau khi restore:
- Cac bang Dimension: DIM_Club, DIM_Competition, DIM_Game, DIM_Player, DIM_Time
- Bang Fact: FACT_Player_Match_Perf (1,894,350 dong)
